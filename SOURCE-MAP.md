# Source and intentional changes

Source reviewed: the entire text of the uploaded **AI Practice and Self-Assessment Guide.docx**, retrieved from the referenced Create Study Plugin conversation. Its title is **Week 2 — AI Practice & Self-Assessment Guide**, covering shock, hematologic, and infectious disease emergencies. This guide defines tutoring behavior; it is not clinical evidence for answer keys.

| Original section | Implementation |
|---|---|
| Scope / command list | Fresh session scope, exact student labels, explicit changes; pre-supplied current topics avoid a redundant question |
| How to run the session | Four options, one item, commitment, brief feedback, set-end teaching; reasoning now occurs before correctness |
| End-of-set A–D | Answer key, misses, patterns, 3–5 review priorities (fewer if unsupported) |
| Once 20 questions answered | Automatic report at 20 valid independent session items; assisted and void questions no longer inflate the trigger |
| Memory bank | Versioned evidence records, deduplication, conflict review, legacy import, student-controlled export |
| How I appear to learn | Descriptive observations with sample requirements; no learning-style, fatigue, or attention diagnosis |
| Comprehensive analysis | Matched comparisons and explicit insufficient-data sections; early full reports allowed without invented findings |
| Instructor section | Preserved 5–8 factual lines, now off by default and never shared automatically |
| Textbook/lecture precedence | Source-only default with attached materials, locators, conflict handling, withheld scoring for uncertainty |

The Week 2 topic list is an example only, never a default scope: Sickle cell crisis; Thrombocytopenia; Coagulation / clotting-factor disorders; Disseminated intravascular coagulation (DIC); Hemorrhagic shock; Transfusion reaction; Neutropenic fever; Leukemia / lymphoma emergencies; Polycythemia; von Willebrand disease; Bacteremia; Sepsis.

The original responsibility disclaimer has been replaced with concise educational limitations rather than new liability language. Thresholds for adaptation and reporting are implementation choices, not clinical or psychometric findings.
